# MA STUDIO — FUTURISTIC LUXURY PHOTOGRAPHY WEBSITE

Act as an award-winning creative director, senior UI/UX designer and full-stack developer.

Create a complete, premium, futuristic photography website for a brand named **MA Studio**.

The website must combine two visual directions:
1. Cinematic black-and-gold photography studio aesthetic.
2. Modern luxury editorial design with elegant typography, premium photography layouts and futuristic details.

IMPORTANT: Preserve the original black and champagne-gold color palette throughout the entire website.
